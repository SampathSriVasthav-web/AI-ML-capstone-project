# Titanic Analytics Pipeline

## Objective

The objective of this project is to perform exploratory data analysis, data preprocessing, predictive modeling, and model evaluation using the Titanic dataset.

## Tasks Performed

- Data Loading
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- Standardization
- Stratified Train-Test Split
- Machine Learning Pipeline
- Logistic Regression
- Decision Tree
- Random Forest
- Model Evaluation
- Hyperparameter Tuning
- SMOTE
- Multiple Linear Regression
- Residual Analysis
- Model Comparison
- Joblib Model Saving

## Best Model

### Final Recommendation

Among the evaluated models, Logistic Regression achieved the best overall performance, with an accuracy of approximately 83.24% and a ROC-AUC score of approximately 0.869. Therefore, Logistic Regression is recommended as the best-performing model for this classification task.
